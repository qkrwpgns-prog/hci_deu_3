# hci_deu_3

조별과제 일정 조율 — 인터뷰 카드에서 페르소나까지 (8주차 과제)

- `docs/persona-report-v6.pdf` : 최종 정리 문서 (카드 분류, 행동변수, 점도표, 페르소나)
- `data/cards.csv` : 의미 단위 카드 238장 원본
- `docs/interviews/` : 인터뷰 자료 (P1–P3 질문별 답변 정리, P8–P10 녹취 전사 PDF, P8–P11 녹취 전사 텍스트, P4–P7 인터뷰 자료)
- `docs/personas.md` : 페르소나 3종 전문 (특징·W8 표·근거 카드)
- `data/variables.csv`(참여자×행동변수 점수), `data/participants.csv`, `data/variable_evidence.csv`, `data/transcripts.md` : 참여자 정보, 행동변수 근거, 익명화 전사본
- `data/README.md` : 자료 안내와 행동변수 정의
- `docs/기획서_v2.md` : 서비스 기획서 v2 (경쟁 분석, 차별점, KPI, 심사 점검, IA, 화면 흐름, 디자인 방향)
- `design/prototype.html` : 클릭 프로토타입 (브라우저로 열기, 시나리오 A~F). `flow/flow.md`의 플로우 1~4와 갈림길을 모두 이어 둠. `design/screens.md`에 화면 순서표와 점검 기록
