# 서비스 플로우

## 플로우 1: 팀원 이수아가 들어와 남의 진행을 보고 초안을 올린다 [핵심]
퍼소나: 이수아 (맡은 몫을 미리 해 두는 팀원, P3·P6·P11) / 목표: 다른 팀원이 어디까지 했는지 보고, 내 초안을 눈치 보지 않고 올린다 (근거: P6-64b, P6-38a)
| 단계 | 화면 (ID) | 사용자 행동 | 다음 화면 | 갈림길 |
|---|---|---|---|---|
| 1 | 링크로 들어오기 (04) | 단톡방에서 팀장이 보낸 링크를 눌러 들어와, 이름만 적고 "팀 들어가기"를 누른다 | 팀 진행 (06) | 이름을 비우고 누름: 같은 화면에 "이름을 적어 주세요" 안내 / 링크가 잘못됨: 오류 · 잘못된 링크 (12-A)에서 "팀장에게 링크 다시 받기" 문구를 복사해 단톡방에 붙여 넣고, 새 링크로 링크로 들어오기 (04) |
| 2 | 팀 진행 (06) | 팀원 × 단계 진행판을 보고, 먼저 올린 팀원의 칸(카드)을 누른다 | 팀원 파트 · 결과물 보기 (07) | 아직 아무도 안 올림: 빈 상태 (11)에서 "내 결과물 올리기" (먼저 올려도 팀원 알림 없음 안내) → 결과물 올리기 (08) / 내 칸을 누름: 내 파트 (07-b) → 뒤로 팀 진행 (06) / 기한 지난 팀원 칸을 누름: 기한 지남 팀원 (07-c)에서 "팀에 이미 한 번 알렸어요. 따로 말하지 않아도 돼요" 안내를 보고, 원하면 "도울 수 있어요"(보조 버튼)를 누름 → 그 팀원에게만 누가 눌렀는지 안 보이게 "팀원 1명이 ○○를 도울 수 있대요" 알림 → 뒤로 팀 진행 (06) / 남의 것을 안 보고 바로 "내 결과물 올리기": 결과물 올리기 (08) |
| 3 | 팀원 파트 · 결과물 보기 (07) | 팀원이 올린 결과물(파일·링크·메모)을 열어 보고 "확인했어요"를 누른 뒤 "뒤로"를 누른다. 누를 때 한 줄을 남길 수 있다(선택, 예: "방향 좋아요", "분량 딱 맞아요") | 팀 진행 (06) | 결과물이 열리지 않음(권한 없음·지워짐): 같은 화면(07)에 "열 수 없어요" 안내, 올린 사람에게 다시 올려 달라고 알림 / "확인했어요"를 안 누르고 뒤로: 팀 진행 (06), 올린 사람에게 반응 없음 / 이미 확인한 결과물: 버튼이 "확인함"으로 바뀌어 있음 / 한 줄을 남김: 올린 사람의 알림 · 나에게만 (10-b)과 06 상단 띠에 확인과 함께 그 한 줄이 보임 |
| 4 | 팀 진행 (06) | 팀원 진행을 확인한 뒤 하단의 "내 결과물 올리기"를 누른다 | 결과물 올리기 (08) | 아직 맡은 파트가 없음: 단계·파트 정하기 (05)에서 스스로 파트를 맡고 저장 → 팀 진행 (06) / 내 단계를 이미 다 올림: 버튼 대신 "다 올렸어요" 안내 / 올리기 대신 연장: 연장 요청 (09) |
| 5 | 결과물 올리기 (08) | 올릴 단계로 "초안"을 고르고, 파일·링크·한 줄 메모 중 하나를 넣은 뒤 "올리기"를 누른다. 화면에 "올린 뒤에도 언제든 다시 올릴 수 있어요" 안내가 있다 | 올린 직후 (06-b): 내 "초안" 칸이 올림으로 바뀌고 "올렸어요 · 팀원이 확인하면 알려 드릴게요" 안내, 팀원 알림 없음 (끝). 팀원이 확인하면 알림 · 나에게만 (10-b)으로 알림 | 파일이 너무 큼: 오류 · 업로드 실패 (12-B) → "링크로 올리기" 또는 "다시 시도"로 결과물 올리기 (08) / 아무것도 안 넣고 누름: 같은 화면에 "파일·링크·메모 중 하나를 넣어 주세요" 안내 / 올리다 그만둠: "뒤로"로 팀 진행 (06), 내 칸은 그대로 / 아직 완성이 아님: "아직 고치는 중"을 골라 올림 → 올린 직후 (06-b), 내 칸이 "올림(고치는 중)"으로 보임 / 올린 뒤 고치고 싶음: 올린 직후 (06-b)에서 내 칸을 눌러 내 파트 (07-b) → 올린 칸의 "다시 올리기" → 결과물 올리기 (08), 새 버전이 보이고 예전 것은 "이전 버전"으로 남음, 팀원 알림 없음 / 단톡에도 알리고 싶음(선택): 올린 직후 (06-b)의 "단톡에 알리기" → "이수아님이 초안을 올렸어요 + 팀 링크" 문구로 카톡 보내기 또는 복사 → 단톡방에 보이는 모습 (13) → 앱으로 돌아오면 올린 직후 (06-b) |

## 플로우 2: 팀장 김민수가 팀을 만들고 링크를 퍼뜨린다
퍼소나: 김민수 (미리 정리하고 직접 연락하는 팀장, P1·P4·P10) / 목표: 팀을 만들고 팀원 모두가 링크로 들어오게 한다 (근거: P4-12 "제가 안 하면 아무도 안 할 것 같았어요")
| 단계 | 화면 (ID) | 사용자 행동 | 다음 화면 | 갈림길 |
|---|---|---|---|---|
| 1 | 홈 · 내 팀 목록 (01) | 서비스를 열어 과목별 팀 목록과 "내가 할 다음 단계"를 보고 (다른 과목 팀이 이미 있을 수 있음), "새 팀 만들기"를 누른다 | 팀 만들기 (02) | 처음 써서 팀이 없음: 홈이 비어 있고 "새 팀 만들기"만 크게 보임 → 팀 만들기 (02) / 다른 팀원이 같은 과제 팀을 이미 만들었을 수 있음: 팀 만들기 (02)에 "팀원에게 받은 링크가 있으면 그걸로 들어가세요" 안내 / 새 팀 대신 다른 과목 팀을 누름: 팀 진행 (06) |
| 2 | 팀 만들기 (02) | 과제 이름을 적고(예: 마케팅원론 기말 발표), 팀 마감을 고르고(예: 11/20 금), 과제 유형 4종 중 하나를 고른 뒤 "팀 만들고 링크 받기"를 누른다 | 링크 공유 (03) | 과제 이름을 비우고 누름: 같은 화면에 "과제 이름을 적어 주세요" 안내 / 팀 마감을 오늘보다 이전 날짜로 고름: 같은 화면에 "오늘 이후 날짜를 골라 주세요" 안내 / 과제 유형이 4종에 맞지 않음: "기타"를 골라 단계 없이 시작하고 단계·파트 정하기 (05)에서 직접 단계를 만듦 / 만들다 그만둠: "뒤로"로 홈 · 내 팀 목록 (01) |
| 3 | 링크 공유 (03) | 팀 링크를 보고 "카톡으로 보내기"(또는 복사)로 단톡방에 링크를 보낸 뒤 "다음: 단계 정하기"를 누른다 | 단계·파트 정하기 (05) | 카톡 보내기가 안 됨(PC 등): "복사"를 눌러 직접 붙여 넣음, 같은 화면에 "복사했어요" 안내 / 링크를 안 보내고 다음으로: 그대로 단계·파트 정하기 (05), 링크는 나중에 빈 상태 (11)의 "링크 다시 공유"에서 다시 받음 / 단계 정하기를 미루고 나감: "뒤로"로 홈 · 내 팀 목록 (01), 새 팀이 "새 팀" 배지와 함께 보임 |
| 4 | 단계·파트 정하기 (05) | 과제 유형에 맞게 제안된 단계와 기한(예: 자료조사 → 초안 → 발표자료 → 최종)을 보고 필요하면 고친 뒤, 아직 나만 있으니 파트만 만들어 두고(들어온 사람이 맡음) "이대로 시작하기"를 누른다 | 빈 상태 (11): 아직 아무도 안 들어오고 올라온 것 없음, 안 들어온 팀원·"링크 다시 공유"·"내 결과물 올리기"가 보임 | 단계 기한이 팀 마감보다 늦음: 같은 화면에 "팀 마감(11/20) 전으로 골라 주세요" 안내 / 단계를 모두 지움: 같은 화면에 "단계를 하나 이상 만들어 주세요" 안내 / 파트를 안 만들고 시작: 그대로 빈 상태 (11), 들어온 팀원이 팀 진행 (06)의 "맡은 파트 없음"에서 단계·파트 정하기 (05)로 와 스스로 맡음 (플로우 1과 이어짐) / 정하다 그만둠: "뒤로"로 링크 공유 (03), 제안된 단계는 그대로 저장 |
| 5 | 빈 상태 (11) | | | |
