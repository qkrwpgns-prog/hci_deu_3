# 클로드용 자료 안내 (조별과제 일정 조율 · W8)

이 폴더는 `조별과제_일정조율_패턴과_페르소나_v5.pdf`를 클로드가 읽을 때 같이 넣는 자료다. PDF는 사람이 보기 좋게 만든 것이고, 이 폴더는 클로드가 표·검색·대조에 쓰기 쉽게 뽑은 것이다.

## 파일
| 파일 | 내용 | 언제 쓰나 |
|---|---|---|
| cards.csv | 의미 단위 카드 238장 (ID·묶음·상황·행동·원문줄) | 카드 검색, 묶음별 정리, 근거 확인 |
| variables.csv | 참여자 11명 × 행동변수 V1–V7 점수(−2…+2, 미확인) + 패턴 | 점도표 재현, 패턴 검증 |
| variable_evidence.csv | 변수별 점수 근거 카드 | 점수가 맞는지 확인 |
| participants.csv | 참여자 정보와 카드 수 | 표본 설명 |
| personas.md | 페르소나 3종 전문 (특징·W8 표·발언·차이) | 페르소나 수정·인용 |
| transcripts.md | 익명화 전사본 (줄번호 포함) | 카드 원문 대조 |

## 읽는 순서
분석 흐름은 전사본 → 카드 → 묶음(A–J) → 행동변수(V1–V7) → 점도표 → 패턴 → 페르소나다. 

## 규칙
- 카드ID `P1-26a` = 참여자 P1, 전사 26번째 줄, a는 한 줄을 나눈 첫 카드.
- 근거 없는 표현은 쓰지 않는다. 근거가 없으면 [가정]으로 표시한다.
- 점수 0과 "미확인"은 다르다. 미확인은 근거 카드가 없는 경우다(V6의 P2·P7, V3의 P6 등).
- 패턴: A(P1·P5·P10), B(P3·P7·P11), C(P2·P6·P8·P9), 흩어진 참여자 X(P4).
- 실명은 지웠다. 페르소나 이름(김민수·이수아·한도윤)은 가상이다.

## 알려진 한계 (검토 필요)
- P7의 V3·V4 근거가 약해 패턴 B가 여기에 기댄다.
- V2는 B와 C를 가르지 못한다. 카드 투표(P5·P9)를 +1로 둔 것은 판단이라 팀원과 확인이 필요하다.
- 참여자별 자료량 차이가 크다 (P1 44장, P7 12장).
- P10의 V7은 습관 발언에서, P11의 V6은 해석에서 나왔다.

## 묶음 (A–J)
- A: 회의 가능한 시간을 모아 일정을 정한다 (38장)
- B: 일정 조율 도구를 쓰거나 쓰지 않는다 (32장)
- C: 다른 팀원의 반응을 의식해 말을 아낀다 (11장)
- D: 역할을 나누고 책임을 맡는다 (32장)
- E: 맡은 작업을 저마다 다른 시점에 시작하고 낸다 (25장)
- F: 다른 사람의 진행 상황을 확인하거나 반응을 기다린다 (17장)
- G: 일이 늦어지면 직접 연락하거나 일을 다시 나눈다 (32장)
- H: 결과물 수준과 들일 시간을 저울질한다 (38장)
- I: 과제 방향을 맞추거나 다시 잡는다 (7장)
- J: 팀원 모두의 연락과 참여를 중요하게 여긴다 (6장)

## 행동변수 (−2 ↔ +2)

- **V1 팀 안에서의 역할**: −2 = 주도한다 (팀장·일정 정리 담당) ↔ +2 = 따라간다 (정해진 부분만 한다)
  - 기준: 팀장 여부와 역할을 정한 방식 (Q3·Q5·Q9). −2 팀장으로 일정·역할을 정함 / +1 팀장·조장이 이끄는 팀에서 자기 몫을 스스로 맡음 / +2 역할을 배정받거나, 일정 논의에서 빠져 정해지면 따름
- **V2 일정 조율 방식**: −2 = 단톡방 대화로 맞춘다 ↔ +2 = 도구(시간 투표, 캘린더, 노션)로 맞춘다
  - 기준: 회의 시간을 실제로 맞춘 방법 (Q3·Q4). 카톡 투표는 시간 투표(도구 쪽)지만 단톡방 안의 기능이라 +1. 캘린더가 실패해 개인톡·엑셀로 맞춘 P4는 0
- **V3 작업 진행 시점**: −2 = 미리 나눠서 꾸준히 한다 ↔ +2 = 마감 직전에 몰아서 한다
  - 기준: 자기 몫을 시작한 때와 진행 방식 (Q6). 조금 미리 손대고 본 작업을 직전에 한 경우(P2·P4)는 본 작업 기준. P6은 시작 시점을 말하지 않음
- **V4 중요한 가치**: −2 = 결과물 완성도(학점) ↔ +2 = 들이는 시간·에너지 최소화
  - 기준: 목표와 그 이유 (Q7). "일단 완성"을 목표로 한 경우는 가운데(0)
- **V5 회의 일정을 정하는 방식**: −2 = 수업 시간·처음 계획으로 고정 ↔ +2 = 그때그때 새로 조율
  - 기준: 회의 일정을 정한 방식 (Q2~Q4). −2 수업 시간·처음 계획으로만 / −1 정해 둔 일정 + 필요할 때 추가 / +1 팀장이 시간을 정해 공지 / +2 회의마다 팀원 가능 시간을 모아 새로 맞춤
- **V6 연락이 끊겼을 때 대응**: −2 = 직접 연락하고 대신 처리 ↔ +2 = 기다리거나 팀장에게 맡김
  - 기준: 다른 팀원과 연락이 끊겼을 때 본인이 한 행동과 해결한 사람 (Q9). P2는 본인이 연락이 안 되던 쪽, P7은 그런 일을 겪지 않아 미확인. P11은 녹취 문장이 앞뒤가 맞지 않아 해석이 들어감
- **V7 마무리 방식**: −2 = 끝까지 더 다듬는다 ↔ +2 = 핵심이 되면 마무리한다
  - 기준: 마지막에 더 손댈지 정한 실제 선택과 조건 (Q10). 미완성이라 당일까지 작업한 P9는 0. P10은 평소 습관으로 답함
